# 🐍 Python Daily Practice

A structured workspace for consistent Python learning and skill development.

## 📁 Folder Organization

### **01-basics/**
Fundamental Python concepts
- Variables, data types, operators
- Control flow (if/else, loops)
- Functions and methods
- String manipulation
- *Examples: example_loops.py*

### **02-algorithms/**
Algorithm implementations
- Sorting and searching
- Mathematical algorithms (Fibonacci, Leap Year)
- Recursion
- Problem-solving patterns
- *Examples: fibonacci.py, leap_year.py*

### **03-data-structures/**
Data structure practice
- Lists, tuples, sets, dictionaries
- Stacks and queues
- Linked lists
- Trees and graphs

### **04-projects/**
Complete mini-projects
- Real-world applications
- Integration of multiple concepts
- File handling, data processing
- Web scraping basics

### **data/**
Sample data files for practice
- CSV files (test.csv)
- JSON data
- Test datasets

### **tests/**
Testing and validation
- Unit tests
- Test cases
- Pytest examples

---

## 🎯 Daily Practice Routine

1. **Pick a topic** from one of the folders above
2. **Create a file** with descriptive name: `day01_topic.py`
3. **Add comments & docstrings** to document your learning
4. **Write test code** to verify your solution
5. **Track progress** in the log below
